# PaperFrame V2 服务器部署

目标结构：Nginx 只接受公网请求，Node 仅监听服务器本机的 `8080` 端口；票券记录和留言写入 `/var/lib/paperframe`，不放在网站代码目录。

## 1. 上传代码

服务器安装 Node.js 20 LTS、Nginx 和 Certbot。把仓库放到 `/opt/paperframe/current`，然后执行：

```bash
cd /opt/paperframe/current
npm ci --omit=dev
npm run check
sudo useradd --system --home /var/lib/paperframe --shell /usr/sbin/nologin paperframe
sudo install -d -o paperframe -g paperframe -m 700 /var/lib/paperframe
```

源码素材目录 `壁纸`、`个人主页`、`可用动作`、`vrm动画`、`VRMA_MotionPack`、`fm_vrma_motion_pack_01`、`exports` 和压缩包不属于运行时文件，不要上传到生产目录。

## 2. 私密环境变量

复制 `deploy/paperframe.env.example` 到服务器的 `/etc/paperframe.env`，替换域名、API Key 与签名密钥，然后：

```bash
sudo chown root:paperframe /etc/paperframe.env
sudo chmod 640 /etc/paperframe.env
```

`TICKET_SIGNING_SECRET` 可用 `openssl rand -hex 32` 生成。已经在聊天或截图里出现过的 API Key 必须先到厂商后台撤销，再生成新 Key；旧 Key 不可继续部署。

## 3. 启动 Node 服务

```bash
sudo cp deploy/paperframe.service /etc/systemd/system/paperframe.service
sudo systemctl daemon-reload
sudo systemctl enable --now paperframe
sudo systemctl status paperframe
```

## 4. 配置 Nginx 与 HTTPS

先把 `deploy/paperframe.nginx.conf` 中的 `example.com` 全部改为真实域名，再放入 `/etc/nginx/conf.d/paperframe.conf`。首次签发证书时可先只保留 80 端口的 ACME 配置，执行 Certbot 后启用完整配置。

```bash
sudo install -d -m 755 /var/www/certbot
sudo nginx -t
sudo systemctl reload nginx
sudo certbot certonly --webroot -w /var/www/certbot -d example.com -d www.example.com
```

## 5. 更新版本

```bash
cd /opt/paperframe/current
git pull --ff-only
npm ci --omit=dev
npm run check
sudo systemctl restart paperframe
```

每次更新后至少检查首页、记忆库、留言、聊天、票券签发、二维码图片识别和手工凭证校验。留言位于 `/var/lib/paperframe/messages.txt`，票券与签名文件也位于该私有目录；应定期备份，但不能由 Nginx 或 Node 静态公开。
