# 终端命令与满成就奖励现状

> 更新日期：2026-08-18  
> 状态：精简方案已经实施；后续可直接在本文批注改名、删除或调整输出。

## 一、使用规则

- 从开始菜单打开“命令终端”，或按 `Ctrl + K`。
- 按 `Escape` 或关闭按钮退出。
- 命令不区分大小写。
- 只有成功执行一条有效命令，才解锁“首条指令”。
- 终端不执行操作系统命令，也不接受任意脚本。

## 三、特殊协议视觉

### `star`

不再弹一张普通占卜卡，而是短暂进入全屏“精神观测站”：星图连线完成后显示一条与创作节奏有关的观测结果。它不宣称预测未来，也不使用过度中二的台词。

### `summon cat`

不再使用低分辨率像素猫。新的电子猫由网页矢量图形实时绘制，带组装扫描、能量线路、六节点巡检和往返运动；手机端与“减少动态效果”设置都有降级处理。

## 四、满成就奖励

进度仍采用 `06 / 06`。完成全部六项后：

1. 中央奖杯进入闪亮、可领取状态；
2. 访客输入希望印在票上的名称；
3. 服务器从四款票中随机抽取一款，而不是让访客挑选；
4. 服务器生成唯一票号和数字凭证；
5. 客户端只负责合成与下载带名称的图片，真实性以服务器记录为准。

奖励定位是一张可以保存的高级二次元演出式访问票，不再额外增加隐藏命令、权限等级或第七记忆。
