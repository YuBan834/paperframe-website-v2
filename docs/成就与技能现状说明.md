## 一、六项主成就

成就档案只保留六项主线记录。旧浏览器里遗留的历史成就会在初始化时过滤，不再计入奖杯、进度或访问票。

| 成就 | 解锁方式 | 反馈 |
| --- | --- | --- |
| 身份解码 | 在“关于我”里读取 PaperFrame 原子核，并查看至少三颗技能电子 | 原子核与轨道成为探索内容，而不是纯装饰 |
| 星空占卜 | 在终端输入 `star` | 进入全屏“精神观测站”，显示一次克制的星轨观测结果 |
| 沉浸模式 | 从开始菜单真正进入浏览器全屏 | 只有成功进入全屏后才计入，避免误触解锁 |
| 首条指令 | 在终端成功执行任意有效指令 | 打开终端本身不算完成，必须产生一次有效回应 |
| 别点啦！ | 在短时间内连续触碰食蜂操祈五次 | 触发角色生气反应 |
| 猫咪协议 | 在终端输入 `summon cat` | 电子猫巡检六个记忆节点后折返离场 |

完成 `06 / 06` 后，中央奖杯进入可领取状态。访客填写显示名称，服务器随机发放四款访问票中的一款；票号和数字凭证仍由服务器生成。

头像是原子核，十项技能是三层轨道上的十颗电子。轨道分布为内层 3 颗、中层 4 颗、外层 3 颗；点击或聚焦电子会显示阶段与事实说明。

| 序号 | 电子 | 阶段 | 展示口径 |
| --- | --- | --- | --- |
| 01 | HTML | 主要使用 | 搭建网页结构与内容层级 |
| 02 | CSS | 主要使用 | 页面视觉、动效与响应式布局 |
| 03 | JavaScript | 主要使用 | 网页交互、状态与界面逻辑 |
| 04 | Node.js | 项目实践 | 本地开发服务与网站后端能力 |
| 05 | Python | 项目实践 | 脚本、自动化与小型工具 |
| 06 | Godot | 项目实践 | 游戏原型与交互实验 |
| 07 | Electron | 项目实践 | 把网页技术用于桌面应用实验 |
| 08 | Three.js / VRM | 实验方向 | 3D 场景、模型动作与角色交互 |
| 09 | C语言 | 正在学习 | 理解程序基础与更接近底层的表达 |
