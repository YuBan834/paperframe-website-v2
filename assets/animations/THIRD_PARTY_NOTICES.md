## Motion set

The eight files in `assets/animations/character/` are the project's reviewed
VRMA motion set supplied by the site owner. Confirm their redistribution terms
before publishing the repository or a public build.

The motions were selected and then refined in PaperFrame's VRMA Lab before
being connected to the website's character state machine. This workflow credit
does not replace the license review required for every source motion.

`shokuhou.vrm` contains no embedded animation clip. The website's idle motion
is generated locally from a static model-specific stance, breathing, balance,
gaze and blink layers.
