# Media artwork sources

These local images are presentation thumbnails and blurred detail backdrops for
the owner's private media-memory archive. Copyright remains with the
corresponding rightsholders. The live page does not hotlink third-party images.

`mXX.*` is the complete cover/key art shown in the archive list.
`mXX-wallpaper.*` is the landscape art used behind the selected work.
